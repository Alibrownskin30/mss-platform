How this access flow works

Early testers receive selected codes. Codes activate access on the MSS account, while wallet linkage remains flexible and can be replaced later.

1. Account First
Register or sign in
Use your MSS account as the base identity for access, entitlement history, and future controls.
2. Wallet Link
Connect, replace, or disconnect later
Wallet is attached to the account and can be changed without rebuilding the whole user profile.
3. Access Code
Redeem selected early-access codes
Single-use code redemption activates the entitlement window for the approved tester account.
